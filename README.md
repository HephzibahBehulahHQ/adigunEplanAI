## Development

Node.js 24 and npm 11 are the foundation environment. Run `npm ci`, `npm run check`, and `npm run dev` (open the localhost URL Vite prints). In a Windows sandbox that denies workspace symlinks, use `npm ci --workspaces=false`; the same root-pinned tooling can build the web workspace. `npm run build` writes apps/web/dist, including runtime license notices. `npm run test:e2e` runs Chromium workspace checks after `npm exec playwright -- install chromium`. CI runs checks on pushes and pull requests and does not deploy.

The npm workspace contains apps/web and packages/config. The branded workspace supports panel docking, collapse, sizing and visibility; persistent layout/theme/background settings; keyboard-accessible help; and English, German, Yoruba and Nigerian Pidgin interface dictionaries. Native project creation/switching/rename, multi-page documents, local saving, corruption recovery, validated JSON import/export and undo/redo are implemented. Document output language remains independent of UI language. The native 2D editor supports nine original generic electrical glyphs, real pin-to-pin wires, obstacle-aware routing, junction insertion, grid/snapping, selection/transforms, layers, properties and native clipboard across pages. The expanded engineering library currently has 69 original native definitions; [coverage and limits](docs/references/symbol-family-coverage.md) distinguish drawings from verified parts and simulation. The building workspace includes floors, measured polygon rooms, walls/openings, SVG/DXF reference imports, zones/scales, floor-first lighting/socket/switch/board devices, explicit board/circuit assignments, user-entered load schedules and cable/conduit/tray plan routes. Schema 17 adds vertical risers and building documentation, 25 versioned engineering calculation categories, native front/3D panel design, PLC I/O documentation and real drawing/schedule exports. Account and owner-scoped cloud workflows are implemented; legitimate live authenticated verification remains a gate. Adigun BOT and the validated example library are in progress.
