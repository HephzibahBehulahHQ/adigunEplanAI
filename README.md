## Development

Node.js 24 and npm 11 are the foundation environment. Run `npm ci`, `npm run check`, and `npm run dev` (open the localhost URL Vite prints). In a Windows sandbox that denies workspace symlinks, use `npm ci --workspaces=false`; the same root-pinned tooling can build the web workspace. `npm run build` writes apps/web/dist, including runtime license notices. `npm run test:e2e` runs Chromium workspace checks after `npm exec playwright -- install chromium`. CI runs checks on pushes and pull requests and does not deploy.

The npm workspace contains apps/web and packages/config. The branded workspace supports panel docking, collapse, sizing and visibility; persistent layout/theme/background settings; keyboard-accessible help; and English, German, Yoruba and Nigerian Pidgin interface dictionaries. Native project creation/switching/rename, multi-page documents, local saving, corruption recovery, validated JSON import/export and undo/redo are implemented. Document output language remains independent of UI language. The native 2D editor supports nine original generic electrical glyphs, real pin-to-pin wires, obstacle-aware routing, junction insertion, grid/snapping, selection/transforms, layers, properties and native clipboard across pages. The expanded engineering library currently has 69 original native definitions; [coverage and limits](docs/references/symbol-family-coverage.md) distinguish drawings from verified parts and simulation. The building workspace begins with native floors, polygon rooms, measurements and layered straight walls. Building electrical integration remains in progress; calculations, 3D, cloud persistence and Adigun BOT remain later milestones. Exact scope: [specification](docs/MASTER_SPECIFICATION.md).
