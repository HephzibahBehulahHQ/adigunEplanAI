# Risk register

| Risk | Impact | Mitigation / gate |
|---|---|---|
| Broad engineering scope | Unverified behavior | Follow Parts 22–24 milestone and acceptance gates |
| Connectivity/geometry errors | Invalid engineering documents | Stable IDs, deterministic topology and geometry reference tests before integration |
| Calculation assumptions | Incorrect sizing | Unit validation, published references, declared scope and numerical cases |
| Manufacturer data and CAD formats | Licensing or compatibility gaps | Source provenance and explicit supported-format validation |
| 500 project target | Inflated completeness claims | Individual executable validation reports; no count before evidence |
| Hosted AI and persistence | Unauthorized edits/data access | Server authorization, validated previews, confirmation, undo and isolation tests |
| Four-language interface | Incomplete terminology/accessibility | Complete dictionaries, reviewer validation and layout checks |
| Heavy 3D/browser workloads | Slow editing | Benchmark representative models; isolate conversion services |
| Publication access | Work unavailable remotely | Verify remote SHA after authenticated push |
