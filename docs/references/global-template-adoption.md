## Executable integration

`product.config.json` preserves the shared template's fields and adapts them to
the product. Product-specific `authorityPins`, `specification` and `acceptance`
sections add traceability. Account/cloud feature flags describe implemented
workflows, while acceptance flags separately retain the unverified authenticated
production round trip. No Cloudflare deployment or server administrator authority
is invented. The product's guest policy has no inherited ten-minute trial.

The header/footer consume the configured product identity and canonical division.
`npm run template:check`, included in `npm run check`, rejects identity/destination
drift, noncanonical colors, a changed logo/interface, divergent master copies,
missing authorities and unavailable capability claims. Mutation tests prove those
gates reject the relevant changes. Existing browser coverage verifies the single
header logo and actual four-language behavior.

Adigun BOT remains in its verified local read-only mode. Hosted AI, mutating
proposals, full-project completion and the 500-example acceptance gate cannot be
claimed by editing a template flag. Future capability transitions must update the
contract and enforcement alongside implementation and actual acceptance evidence.
