# Native connectivity (Milestone 5 in progress)

Schema 3 adds optional declared terminal capacity/required status, net memberships, wire physical length/color and cable shield bonds. Version-2 migration preserves native electrical identities.

The engine joins physical terminal identities through wires, explicit connection points, anchored matching net labels and declared cable shield bonds. A terminal strip does not short its members. Line crossings and ordinary text do not create connections. Cable conductors retain independent net assignments.

Analysis produces source/destination records, page references, drawing lengths in millimetres and physical lengths only when supplied. It checks required/open terminals, declared capacity, duplicate identifiers/connections, conflicting core assignments and shield configuration. These checks do not establish protection coordination or standards compliance.

Derived net identities preserve previous memberships where possible. Synchronization rebuilds native nets and CONNECT findings while retaining valid findings from other domains. Workspace mutation integration is still pending; callers must recompute after topology edits before persisting derived records.

Renumbering has separate preview and apply commands. Apply validates a clone, rejects stale or repeated targets and duplicate wire/device identifiers, and is undoable through ProjectHistory. Terminal-strip numbering preserves nonnumeric PE and coil designations. The diagnostics workspace now exposes localized findings, computed netlists, source/destination tables, page navigation and numbering previews with cancel/apply. Live analysis recomputes from native electrical entities without presenting persisted derived nets as current. Manual routing and cable/core editing remain pending.

Manual routing is now implemented: select a wire and edit its full sequence of millimetre coordinates, including the two real pin endpoints. Apply rejects nonfinite, repeated, diagonal, out-of-sheet, detached or obstructed paths. Reset restores obstacle-aware automatic routing. Native history supports undo/redo and persisted geometry survives reload. Moving components or adding obstacles that would invalidate a manual route is rejected until the user edits or resets that route; manual points are never silently overwritten. Cable/core editing remains pending.

Wire properties now support explicit drawing color, physical length and assignment to a declared conductor core. New core creation requires its name, color/designation, area and material; no rating is inferred. The diagnostics cable editor creates/updates core memberships, cable length, shielding and explicit bond terminals. Commands reject duplicate membership, cores already owned by another cable and bonds on an unshielded cable. Blank wire properties remove optional declarations without deleting shared conductor records. Existing-core editing remains pending. Verification: 62 unit/tooling tests, 25 Chromium scenarios, type checking, lint, formatting, license metadata, runtime notices and build passed.

Existing-core editing and terminal controls are now implemented. Terminal capacity is an optional declared maximum wire count; clearing it restores unknown capacity. Required-connection flags affect live open-terminal severity. Terminal-strip membership is explicit and never joins electrical nets; duplicate membership or assignment to another strip is rejected. Core edits preserve wire/core identities and refuse changes affecting protected wire layers. Terminal edits similarly respect protected symbol layers. Verification: 63 unit/tooling tests and all 25 Chromium scenarios passed, alongside the complete local build/license gate.

Native project updates now use an electrical transaction: isolate the input, temporarily remove derived references during the physical edit, rebuild nets/findings against prior identities, and validate before history/storage commit. Failed edits retain the preceding snapshot. Deleting graphical representations retains physical terminals referenced by cable shield bonds. Cross-page anchored labels produce persisted shared memberships and terminal buttons navigate to the real page. Verification: 65 unit/tooling tests, the 25-scenario browser regression suite and a separate cross-page navigation/reload scenario passed. Type checking, lint, formatting, license metadata, notices and build passed. Import-time normalization and complete Milestone 5 acceptance remain to be audited.
