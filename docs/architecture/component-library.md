# Component library (Milestone 6 in progress)

The navigator exposes catalog search, category/manufacturer filters, factual ratings, source links, review dates and assignment to a compatible native device. Assignments create/reuse native manufacturer-part records, set the device mapping and declared terminal capacity, update the BOM, and participate in undo/redo and persistence. Incompatible or protected terminal mappings are rejected by domain commands.

The initial catalog contains one sourced Phoenix Contact UK 5 N terminal record; see references/component-catalog-sources.md. Its generic original terminal glyph represents one common potential with two declared connection positions. The mapping is an engineering interpretation, not manufacturer certification. No manufacturer artwork or downloaded datasheet is bundled.

Validation: 68 unit/tooling tests and all 27 Chromium scenarios passed, including search misses, category/manufacturer filters, source links, assignment, BOM, undo/redo and reload. Type checking, lint, formatting, dependency licenses, runtime notices and build passed. Custom-symbol workflows and broader categories remain incomplete.

Custom box-symbol creation and placement are now implemented. Definitions specify dimensions and named electrical pin coordinates relative to the body center. Validation rejects missing, overlapping or out-of-bounds pins and invalid dimensions. Placement reuses the native bounds/collision/router machinery, creates an independent terminal for each pin, and supports wiring, undo/redo and persistence. No internal short circuits or ratings are inferred. Richer artwork and existing-definition editing remain pending. The local gate passed 69 unit/tooling tests; Chromium verified custom creation, pin wiring, undo and reload. The catalog regression selector was updated to target its outer disclosure after adding the nested custom-symbol editor.

Existing custom definitions can now be edited. All affected instances retain their identities; unchanged pins/terminals and wire endpoints retain theirs. Added pins create distinct terminals on each instance. Removing instantiated pin identities is rejected. Bounds, collisions, protected layers and affected automatic routes are checked before commit; manual routes that would change require explicit user editing/reset. The editor participates in native history. The local gate passed 70 unit/tooling tests, and the focused Chromium custom-symbol workflow passed creation, wiring, reload, pin-preserving geometry edits, rerouting and undo. Richer graphical artwork remains pending.

Schema 4 adds optional original vector artwork composed of explicit lines and circles. Artwork is bounded by the declared custom-symbol body, limited to 256 shapes and validated on import as well as creation/editing. The renderer creates native SVG primitives without accepting raw SVG markup, URLs or script. Blank artwork retains the box glyph. Version-2/3 migration preserves electrical IDs; earlier migrations remain supported. The complete local gate passed 71 unit/tooling tests and all 28 Chromium scenarios, including artwork rendering, definition editing, reload, migration and native export. Broader library categories and catalog coverage remain Milestone 6 work.

Six original generic definitions now cover a two-winding transformer, battery, normally closed contact, three-phase motor, voltmeter and L/N/PE socket. Category/search controls import editable native definitions. Each has distinct original artwork and explicit independent pins; component-internal conduction or simulation is not inferred by the net engine. These are original engineering diagrams without standards certification or manufacturer ratings. Imports preserve existing local edits rather than overwriting definitions. Unit checks installed and placed all six, checked pin identities and native serialization. The 72-test local gate and a focused Chromium transformer search/import/placement/undo/reload test passed. Protection, automation and industrial-control expansion remains pending.

The library now also includes a single-pole circuit breaker, a three-wire sensor and a variable-frequency drive. Their two, three and seven independent electrical pins are explicitly named; each has distinct original geometry. The common unit loop installs, places and serializes all nine symbols, and category-search assertions cover the new records. The 72-test local gate, type checking, lint, formatting, licensing, notices and build passed. These additions are generic schematic definitions, not protection simulation or executable automation. Broader specified families, per-pin electrical-kind metadata and manufacturer coverage remain incomplete.

Schema 5 adds optional per-pin electrical kinds (power, control, signal, PE and neutral). New library placements use explicitly declared types, including PE and neutral for applicable terminals. Custom rows accept an optional fourth kind field; editing a declaration updates the corresponding existing terminals without changing identities. Missing declarations preserve legacy behavior; version-4 migration preserves prior terminal values rather than guessing intent. Full local verification passed 73 unit/tooling tests, all 29 Chromium scenarios and build/license gates.
