# Component library (Milestone 6 in progress)

The navigator exposes catalog search, category/manufacturer filters, factual ratings, source links, review dates and assignment to a compatible native device. Assignments create/reuse native manufacturer-part records, set the device mapping and declared terminal capacity, update the BOM, and participate in undo/redo and persistence. Incompatible or protected terminal mappings are rejected by domain commands.

The initial catalog contains one sourced Phoenix Contact UK 5 N terminal record; see references/component-catalog-sources.md. Its generic original terminal glyph represents one common potential with two declared connection positions. The mapping is an engineering interpretation, not manufacturer certification. No manufacturer artwork or downloaded datasheet is bundled.
