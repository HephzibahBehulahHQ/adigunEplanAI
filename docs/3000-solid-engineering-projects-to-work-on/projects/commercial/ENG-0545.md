# ENG-0545 — Community-centre distribution — Supply undervoltage supervision

Status: **planned; not an implemented, tested or installation-approved design**.

Domain: Commercial buildings. Base system: Community-centre distribution.

Engineering scope: hall lighting, stage feeder boundary, catering circuits, emergency-service interface.

Distinct requirement: Add supply-monitoring contacts and a defined loss-of-voltage inhibit path.

Functional acceptance: Test undervoltage inhibit and documented restart policy.

Use one native project, four section containers, and the 30 sheets below. Engineering assumptions must be explicit; add sheets when complexity requires them. Read [the handoff](../../NEXT_AGENT.md) before implementation.
