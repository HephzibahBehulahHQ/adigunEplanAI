# ENG-0294 — Residential outbuilding distribution — Controlled shutdown interface

Status: **planned; not an implemented, tested or installation-approved design**.

Domain: Residential installations. Base system: Residential outbuilding distribution.

Engineering scope: buried feeder interfaces, shed subboard, outdoor sockets, external lighting.

Distinct requirement: Add a plant shutdown input and ordered deactivation outputs; distinguish operational stop from safety functions.

Functional acceptance: Test shutdown order, residual-energy documentation and restart authorisation.
