# ENG-1227 — Motor-control centre section — Distributed field enclosure

Status: **planned; not an implemented, tested or installation-approved design**.

Domain: Control cabinets and panels. Base system: Motor-control centre section.

Engineering scope: starter buckets, control transformer, common terminals, feeder isolation.

Distinct requirement: Move identified field terminals into a second enclosure with an interconnecting cable schedule.

Functional acceptance: Verify end-to-end terminal mapping, screen continuity and cross-enclosure isolation boundaries.

Use one native project, four section containers, and the 30 sheets below. Engineering assumptions must be explicit; add sheets when complexity requires them. Read [the handoff](../../NEXT_AGENT.md) before implementation.
